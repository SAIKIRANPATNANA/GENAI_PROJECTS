# Machine Learning

**Source document:** machine_learning.md
**Course code:** AI301

## Overview

Machine Learning covers supervised and unsupervised learning: linear and logistic regression, decision trees, clustering, and model evaluation techniques such as cross-validation.

## Prerequisites

Statistics for Data-Driven Fields (STAT201) and Python Programming Fundamentals (CS101). The course assumes working knowledge of probability, hypothesis testing, and Python, since assignments involve fitting models with scikit-learn.

## Learning Outcomes

- Train and evaluate supervised learning models
- Apply clustering techniques to unlabeled data
- Use cross-validation to avoid overfitting
- Interpret model evaluation metrics

## Notes

Students who complete this course have the quantitative and programming foundation to continue into more advanced, specialized electives later in the curriculum.
