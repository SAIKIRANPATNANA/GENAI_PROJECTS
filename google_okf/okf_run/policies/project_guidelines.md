# Capstone Project Guidelines

## Overview

Administrative guidance for the final-year capstone project, including submission format, deadlines, and academic integrity requirements.

## Submission

A PDF report (maximum **40 pages**) plus a source code repository, submitted through the department portal.

## Deadlines

| Milestone        | Due      |
|------------------|----------|
| Project proposal | Week 4   |
| Final submission | Week 24  |

## Academic Integrity

All code and writing must be original. Plagiarism results in automatic referral to the academic conduct board.
