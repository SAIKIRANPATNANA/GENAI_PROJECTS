# Statistics for Data-Driven Fields

**Course code:** STAT201

## Overview

This course covers descriptive and inferential statistics, probability distributions, hypothesis testing, and an introduction to regression. Weekly labs use computational tools to compute and visualize distributions on real datasets.

## Prerequisites

[Python Programming Fundamentals](./python_prerequisites.md) (CS101). Students should be comfortable writing basic scripts before enrolling, since lab exercises use Python (pandas/NumPy) for every computation and visualization.

## Learning Outcomes

- Compute descriptive statistics on a dataset
- Understand and apply common probability distributions
- Run and interpret hypothesis tests
- Fit and interpret simple regression models

## Notes

This course does not cover machine learning topics directly, but it is treated as a foundational quantitative course for later analytical electives.
