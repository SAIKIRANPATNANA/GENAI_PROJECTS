# Courses

Academic course concepts for the AI/Cybersecurity curriculum, organized by tier.

# Foundation Tier — No Prerequisites

* [Python Programming Fundamentals](./python_prerequisites.md) — Entry-level Python: variables, control flow, data structures, NumPy (CS101)
* [Artificial Intelligence Foundations](./artificial_intelligence.md) — Survey of AI subfields, search, and planning (AI201)

# Quantitative Tier — Requires CS101

* [Statistics for Data-Driven Fields](./statistics_prerequisites.md) — Probability, hypothesis testing, regression using Python/pandas (STAT201)

# Core AI Tier — Requires CS101 + STAT201

* [Machine Learning](./machine_learning.md) — Supervised & unsupervised learning, cross-validation, scikit-learn (AI301)
* [Data Science](./data_science.md) — End-to-end data analysis, EDA, visualization, applied ML (DS301)

# Advanced Tier — Requires AI301

* [Deep Learning](./deep_learning.md) — Neural networks, backpropagation, CNNs, RNNs (AI401)

# Specialization Electives — Requires AI401

* [Computer Vision](./computer_vision.md) — Image classification, object detection, transfer learning (AI411)
* [Natural Language Processing](./nlp.md) — Embeddings, sequence models, transformers (AI412)
