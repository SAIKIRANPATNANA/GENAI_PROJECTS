# Deep Learning

**Course code:** AI401

## Overview

Deep Learning introduces neural network architectures, backpropagation, gradient-based optimization, and regularization, with a first look at convolutional and recurrent network structures.

## Prerequisites

[Machine Learning](./machine_learning.md) (AI301). Students are expected to already understand supervised learning, model evaluation, and the basics of optimization before this course introduces neural networks.

## Learning Outcomes

- Implement and train feedforward neural networks
- Apply backpropagation and gradient-based optimization
- Use regularization techniques to control overfitting
- Understand the basic building blocks of CNNs and RNNs

## Notes

The neural network concepts introduced here underpin the specialized electives offered later in the program, which apply deep learning to specific domains.
