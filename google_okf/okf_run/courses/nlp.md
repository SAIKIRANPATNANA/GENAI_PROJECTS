# Natural Language Processing

**Course code:** AI412

## Overview

This course covers text preprocessing, word and sentence embeddings, sequence models, attention mechanisms, and transformer architectures.

## Prerequisites

[Deep Learning](./deep_learning.md) (AI401). The course extends the neural network foundations from Deep Learning into sequence models and attention-based architectures.

## Learning Outcomes

- Build text classifiers using embeddings
- Work with sequence models and attention mechanisms
- Implement core components of transformer architectures

## Notes

NLP and [Computer Vision](./computer_vision.md) are parallel specialization tracks that both build directly on [Deep Learning](./deep_learning.md), though neither depends on the other.
