# Data Science

**Course code:** DS301

## Overview

Data Science covers end-to-end data analysis workflows: data cleaning, exploratory analysis, visualization, and the applied use of machine learning techniques for predictive analytics.

## Prerequisites

[Statistics for Data-Driven Fields](./statistics_prerequisites.md) (STAT201) and [Python Programming Fundamentals](./python_prerequisites.md) (CS101).

## Learning Outcomes

- Clean and explore real-world datasets
- Build visualizations to communicate findings
- Apply machine learning models to analytical problems
- Communicate results to non-technical stakeholders

## Notes

Data Science draws heavily on [Machine Learning](./machine_learning.md) techniques for its predictive-analytics modules, though it approaches modeling from an applied, workflow-oriented perspective rather than the algorithmic depth covered in the Machine Learning course itself.
