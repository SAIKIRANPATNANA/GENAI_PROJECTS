# Computer Vision

**Course code:** AI411

## Overview

Computer Vision covers image classification, object detection, and convolutional neural network (CNN) architectures, along with transfer learning from pretrained vision models.

## Prerequisites

[Deep Learning](./deep_learning.md) (AI401). The course builds directly on the convolutional network concepts and gradient-based training covered there.

## Learning Outcomes

- Build and train CNNs for image classification and detection
- Apply transfer learning to new vision tasks
- Evaluate vision model performance

## Notes

Computer Vision is one of two specialization electives that follow directly from [Deep Learning](./deep_learning.md), the other being [Natural Language Processing](./nlp.md).
