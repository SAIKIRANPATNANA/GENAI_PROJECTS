# Python Programming Fundamentals

**Source document:** python_prerequisites.md
**Course code:** CS101

## Overview

Python Programming Fundamentals is the entry-level programming course for the AI/Cybersecurity curriculum. Students learn variables, control flow, functions, core data structures (lists, dictionaries, sets, tuples), basic file I/O, and a first introduction to the NumPy library for numerical work.

## Prerequisites

None. This course is open to all first-year students regardless of prior programming background.

## Learning Outcomes

- Write and debug small Python scripts
- Use core data structures confidently
- Read and write text files
- Understand functions, loops, and basic error handling

## Notes

Comfort with Python is assumed by several later courses in the curriculum, so students planning to continue into quantitative or AI-focused electives are strongly encouraged to complete this course early.
