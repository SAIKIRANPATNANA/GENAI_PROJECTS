# Capstone Project Guidelines

← [Back to Index](../index.md)

## Overview

Administrative guidance for the final-year capstone project — covers submission format, deadlines, and academic integrity requirements. Contains **no course-content or subject-matter information**.

## Submission Requirements

- **Format:** PDF report (maximum 40 pages) + source code repository
- **Platform:** Submitted through the department portal

## Key Deadlines

| Milestone | Due |
|-----------|-----|
| Project Proposal | Week 4 |
| Final Submission | Week 24 |

## Academic Integrity

- All code and writing must be **original**.
- Plagiarism results in **automatic referral to the academic conduct board**.

## Notes

The capstone is the terminal deliverable of the program. Students in the NLP or CV tracks (see [NLP](../courses/nlp.md), [Computer Vision](../courses/computer_vision.md)) typically apply their specialization to a real-world problem for this project.
