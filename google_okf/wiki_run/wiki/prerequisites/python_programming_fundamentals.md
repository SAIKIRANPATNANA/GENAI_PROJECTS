# Python Programming Fundamentals

**Course Code:** CS101
← [Back to Index](../index.md)

## Overview

Entry-level programming course for the AI/Cybersecurity curriculum. Students learn core Python from scratch, with a first look at numerical computing via NumPy.

## Topics Covered

- Variables, control flow (loops, conditionals), functions
- Core data structures: lists, dictionaries, sets, tuples
- Basic file I/O
- Introduction to NumPy for numerical work

## Prerequisites

None. Open to all first-year students regardless of prior programming background.

## Learning Outcomes

- Write and debug small Python scripts
- Use core data structures confidently
- Read and write text files
- Understand functions, loops, and basic error handling

## Notes

Students planning quantitative or AI-focused electives are **strongly encouraged to complete this course early** — Python proficiency is assumed across most of the curriculum.
