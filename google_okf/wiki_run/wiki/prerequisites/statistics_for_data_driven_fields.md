# Statistics for Data-Driven Fields

**Course Code:** STAT201
← [Back to Index](../index.md)

## Overview

Covers the mathematical and probabilistic foundations needed for data analysis and machine learning. Lab work is computational — students use Python (pandas/NumPy) to apply every concept to real datasets.

## Topics Covered

- Descriptive statistics (mean, variance, distributions)
- Inferential statistics and probability distributions
- Hypothesis testing
- Introduction to regression (simple linear regression)

## Prerequisites

| Course | Code | Reason |
|--------|------|--------|
| [Python Programming Fundamentals](../prerequisites/python_programming_fundamentals.md) | CS101 | Labs use Python for all computations and visualizations |

## Learning Outcomes

- Compute descriptive statistics on a dataset
- Understand and apply common probability distributions
- Run and interpret hypothesis tests
- Fit and interpret simple regression models

## Notes

Does **not** cover machine learning topics directly, but is treated as a core quantitative prerequisite for later analytical electives. Think of it as the mathematical lingua franca of the curriculum.
