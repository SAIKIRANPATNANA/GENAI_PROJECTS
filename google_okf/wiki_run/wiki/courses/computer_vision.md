# Computer Vision

**Course Code:** AI411
← [Back to Index](../index.md)

## Overview

Specialization elective extending the CNN foundations from Deep Learning into full vision pipelines — image classification, object detection, and practical transfer learning from pretrained vision models (e.g., ResNet, EfficientNet).

## Topics Covered

- Convolutional Neural Network architectures (LeNet, VGG, ResNet, etc.)
- Image classification pipelines
- Object detection (YOLO, SSD, Faster R-CNN style approaches)
- Transfer learning and fine-tuning from pretrained models
- Vision model evaluation (mAP, IoU, etc.)

## Prerequisites

| Course | Code | Reason |
|--------|------|--------|
| [Deep Learning](deep_learning.md) | AI401 | Builds directly on CNN concepts and gradient-based training covered there |

## Learning Outcomes

- Build and train CNNs for image classification and detection
- Apply transfer learning to new vision tasks
- Evaluate vision model performance

## Parallel Specialization Track

> Computer Vision and [Natural Language Processing](nlp.md) (AI412) are **parallel electives** — both build directly on Deep Learning, but neither depends on the other.

## Notes

One of two terminal specialization electives in the program. After completing this course, students typically move to their capstone project applying vision techniques to a real problem.
