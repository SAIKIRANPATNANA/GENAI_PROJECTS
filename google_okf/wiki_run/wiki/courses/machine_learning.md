# Machine Learning

**Course Code:** AI301
← [Back to Index](../index.md)

## Overview

Core machine learning course covering classical supervised and unsupervised algorithms. Students implement and evaluate models using scikit-learn on real datasets. This is the **gateway course** to the quantitative AI track.

## Topics Covered

- Supervised learning: linear regression, logistic regression, decision trees
- Unsupervised learning: clustering (k-means and variants)
- Model evaluation: cross-validation, bias-variance tradeoff
- Metrics: accuracy, precision, recall, F1, ROC-AUC

| Course | Code | Reason |
|--------|------|--------|
| [Statistics for Data-Driven Fields](../prerequisites/statistics_for_data_driven_fields.md) | STAT201 | Working knowledge of probability and hypothesis testing required |
| [Python Programming Fundamentals](../prerequisites/python_programming_fundamentals.md) | CS101 | Assignments use scikit-learn in Python |

## Learning Outcomes

- Train and evaluate supervised learning models
- Apply clustering techniques to unlabeled data
- Use cross-validation to avoid overfitting
- Interpret model evaluation metrics
