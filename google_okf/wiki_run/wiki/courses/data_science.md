# Data Science

**Course Code:** DS301
← [Back to Index](../index.md)

## Overview

End-to-end applied data analysis — from messy raw data through cleaning, exploratory analysis, visualization, and finally predictive modeling using machine learning techniques. Focuses on **workflow and communication** rather than algorithmic depth.

## Topics Covered

- Data cleaning and preprocessing (handling missing values, outliers, encoding)
- Exploratory data analysis (EDA) and statistical summaries
- Data visualization (matplotlib, seaborn, or similar)
- Applied machine learning for predictive analytics
- Communicating findings to non-technical stakeholders

## Prerequisites

| Course | Code | Reason |
|--------|------|--------|
| [Statistics for Data-Driven Fields](../prerequisites/statistics_for_data_driven_fields.md) | STAT201 | Statistical reasoning underpins the entire analytical workflow |
| [Python Programming Fundamentals](../prerequisites/python_programming_fundamentals.md) | CS101 | All data work done programmatically in Python |

## Learning Outcomes

- Clean and explore real-world datasets
- Build visualizations to communicate findings
- Apply machine learning models to analytical problems
- Communicate results to non-technical stakeholders

## Relationship to Machine Learning

> DS301 draws heavily on [Machine Learning](machine_learning.md) (AI301) techniques for predictive-analytics modules, but the two courses **do not formally require each other**. The key difference:
> - **ML (AI301):** algorithmic depth, theory, implementation
> - **Data Science (DS301):** applied workflow, communication, full pipeline

## Notes

This is a parallel track to the AI-depth track (AI301 → AI401 → specializations). Students can take DS301 and AI301 concurrently, or either before the other, provided they have completed STAT201 and CS101.
